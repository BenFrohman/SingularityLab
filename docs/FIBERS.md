# Milnor fibers (schematic)

Author: Benjamin Stanley Frohman (@BenFrohman).

These are diagrams, not photographs. A plane-curve Milnor fiber
is homotopy-equivalent to a bouquet of μ circles.

## W = -1

W = u^5 v + v^6. μ = 25.

    homotopy type: ∨_{25} S^1

W factors as v(u^5 + v^5). Six lines through the origin in the
projectivized tangent cone. The fiber is a 25-circle bouquet.

```
          o—o—o—o—o
         /           \
        o             o     25 loops, one wedge point
         \           /
          o—o—o—o—o
```

## W^T = -1

W^T = u^5 + u v^6. μ = 26.

    homotopy type: ∨_{26} S^1

One extra loop versus W. That extra loop is the F = +1 shift.

SVG copies: `docs/fiber_W.svg`, `docs/fiber_WT.svg`.

Not a Hodge class. Not Fields 2–3.
