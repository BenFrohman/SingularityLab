# The +1

Author: Benjamin Stanley Frohman. (c) 2026. Apache-2.0.

BHK transpose does not keep the same Milnor number.
On this chain pair it keeps a relation:

    μ(W^T) = μ(W) + 1.

    μ(W)    = 25
    μ(W^T)  = 26
    |Aut|    = 30 on both
    ĉ       = 4/3 on both

The +1 is the extra standard monomial on the W^T stairway
(leading terms u^4, u v^5, v^{11} versus u^5, u^4 v, v^6).
It is not a Hodge class and not Fields 2–3.
