# Suspension W + z^2

Author: Benjamin Stanley Frohman. (c) 2026. Apache-2.0.

Named germ, not a duality theorem:

    W_susp(u,v,z) = u^5 v + v^6 + z^2

This is a 3-variable isolated singularity (Thom–Sebastiani with A1).
Milnor number adds in the usual way for TS with z^2:

    μ(W + z^2) = μ(W) · μ(z^2) = 25 · 1 = 25.

(z^2 has μ=1.) It is a different germ from W. Strange duality
(Ebeling–Takahashi / Dolgachev–Gabrielov) is a statement about
certain 3-variable invertible polynomials. Naming W+z^2 does not
run that theorem. The pair (W, W^T) stays 2-variable.

Not a Hodge class. Not Fields 2–3.
